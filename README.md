# FinTrack Lite

FinTrack Lite is a lightweight React + TypeScript expense tracker app. It includes a dashboard, transaction list, chart visualizations, and local data persistence.

## Features

- Transaction add/edit UI
- Summary cards for income, expenses, and balance
- Chart visualization with `recharts`
- Local storage persistence for transactions
- Tailwind CSS styling

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app in the browser.

### Build for production

```bash
npm run build
```

## Project Structure

- `src/` - app source code
- `src/components/` - reusable UI components
- `src/pages/` - application pages
- `src/context/` - React context for transactions
- `src/hooks/` - custom hooks
- `src/utils/` - helper functions and category data

## Dependencies

- React
- TypeScript
- Recharts
- Tailwind CSS
